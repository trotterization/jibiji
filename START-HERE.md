# Start JIBIJI with Claude Code

1. Open Xcode once on your Mac. Clone this repository or pull the latest main if you already have it.
2. Open Claude Code in the cloned jibiji folder. Run /memory and confirm CLAUDE.md is listed. Open [issue #2](https://github.com/trotterization/jibiji/issues/2) and assign yourself if you are starting the prototype.
3. Paste the prompt below. Give Claude normal tool approvals for the task branch and draft PR as needed.

> Read CLAUDE.md and https://github.com/trotterization/jibiji/issues/2. Check my Xcode setup, then create the first native iPad SwiftUI Xcode project and scoped PencilKit prototype on a new branch. Build it, report simulator and iPad checks separately, and push a draft PR linked to issue #2. Stop before merging.

The first draft should let you write, save, and reopen one PencilKit page. Use the draft PR to share the branch, test results, and the next step with the team. See [CLAUDE.md](CLAUDE.md) for the full product and team instructions.
